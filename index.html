Introduzione

JavaScript è un linguaggio di scripting orientato agli oggetti, multipiattaforma e leggero.

All'interno di un ambiente ospite, JavaScript può essere collegato agli oggetti del suo ambiente per fornire un controllo programmatico su di essi.

console.log("Hello World");

  • Estensioni lato server

JavaScript e Java

JavaScript e Java sono simili in alcuni modi ma fondamentalmente diversi in altri.

Il linguaggio JavaScript assomiglia a Java ma non ha la tipizzazione statica e il controllo forte dei tipi di Java.

typeof "Java" !== typeof "JavaScript"

Variabili

Utilizzi le variabili come nomi simbolici per i valori all'interno della tua applicazione.

I nomi delle variabili, chiamati identificatori, devono conformarsi a determinate regole del linguaggio.

var x = 42;
  • Dichiarazione tramite var
  • Dichiarazione tramite let
